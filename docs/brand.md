# slidepig brand and writing

The name is **slidepig**, one word, lowercase. The public home is
<https://slidepig.com>. The product description is **Decks that are web pages.**
The brand line is **Small pig. Big ideas.**

## Product story

slidepig is a simple, lightweight React library for presentations. Lead with
making and editing a deck: use a coding agent with the bundled skill, or edit
ordinary slide files yourself. Then show the result: one responsive page to
read, share, and present. Custom visuals and integrations are possible through
the user's code; do not imply built-in service connections or image generation.
Keep the tone useful and modest. Prefer a small working example to a grand
promise. “Small pig. Big ideas.” supports the product explanation.

## Voice

Friendly, direct, and a little absurd. Explain the feature first; let the pig
supply an occasional wink. A reader should never need to decode a joke to
install the package or understand an API.

Good places for wordplay: headlines, example deck titles, empty states, and
short sign-offs. Keep commands, API names, errors, accessibility labels, and
reference documentation literal. Call decks “decks,” not “sties,” in instructions.

A few lines in the pen:

- “Read it. Present it.”
- “Press F to hog the stage.”
- “A few from the pen.”
- “Oink. Now go make something worth presenting.”

## Look

The public site uses a pale blush background, dark plum text, and restrained
rose accents. Serif headlines pair with a quiet system sans-serif for body
copy. Use regular heading weights, readable line lengths, generous space,
and fine rules to establish hierarchy. Keep the pig in the wordmark.

Prefer open sections and simple linked rows over cards, colored panels,
shadows, and rotation. The brand CSS lives in `apps/demo`; consumer decks
bring their own identities. Use system fonts and avoid adding font downloads,
icon libraries, or runtime dependencies for branding.

## Claims

Describe the concrete behavior: one page reads and presents, slides have hash
links, React is a peer, browser runtime dependencies are zero. Keep size claims
approximate and consistent with `pnpm --filter slidepig size`.

The current license is BSL 1.1. Say **source available**, with free use for
one's own and clients' presentations. Do not call the current release open
source or imply it can be used to offer a presentation-making service. Each
version becomes MPL-2.0 after four years; the LICENSE is authoritative.
